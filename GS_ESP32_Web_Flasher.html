Using a single merged firmware file? This simple mode writes it at 0x0. Only use it if your firmware instructions specify that address. Got bootloader, partitions and app files instead? Open Advanced options below.
3

Flash your device

Make sure the selected firmware matches your board.

Waiting for your firmware and device0%

Your ESP32 must be connected, firmware selected, and the checkbox ticked. We'll ask before writing anything.

Advanced options Multiple .bin files & settings

Change these only if your firmware's installation instructions require it. Flash addresses must match the firmware build.

Addresses can be edited in Step 2 while Advanced options are open. The presets are examples, not verified for every board.

Help and activity log Troubleshooting & progress details

No COM port? Use a USB data cable, install your board's USB driver if needed, or close serial-monitor applications. If the board won't connect, try entering bootloader mode using its BOOT/RESET controls.
